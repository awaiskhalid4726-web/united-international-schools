# United International School Website

This is the final responsive United International School curriculum and learning-resource website.

Included:
- United International School logo
- Home, About, Curriculum, Subjects, Mathematics and Contact sections
- Grade 11 and Grade 12 mathematics areas
- Resource search/filter
- Responsive mobile navigation
- HTML, CSS and JavaScript
- GitHub Pages-ready structure

Before publishing, replace placeholder school contact details and connect the resource buttons to your real PDF/Word/PowerPoint files.

For GitHub Pages, keep `index.html` at the repository root and the `assets` folder beside it. In GitHub go to Settings → Pages → Deploy from a branch → main → / (root) → Save.
